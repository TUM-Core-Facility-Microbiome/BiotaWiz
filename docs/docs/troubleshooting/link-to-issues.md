# Report a bug

If BiotaWiz or TACTIC does something wrong, or a file is not recognised although it should be, please open an
**[issue on GitHub](https://github.com/TUM-Core-Facility-Microbiome/BiotaWiz/issues)**.

Please include:
- what you did, what you expected, and what happened instead,
- your BiotaWiz version (**Settings › About**), the TACTIC version (shown on the **Base** step) and your operating system,
- the error code, if one was shown (see [Error codes](troubleshooting-error-codes)), and
- `Pipeline_log.txt` from your base directory.

Search the existing issues first; someone may already have reported the same problem.
