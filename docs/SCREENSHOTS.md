# Screenshots to capture

The GUI pages contain invisible placeholders like `{/* SCREENSHOT: name.png – what to show */}`.
For each one below:

1. Take the screenshot in BiotaWiz (a window of about 1200×800, light theme, no personal data visible).
2. Save it as `static/img/gui/<name>.png`.
3. Replace the placeholder line in the page with `![<short description>](/img/gui/<name>.png)`.
